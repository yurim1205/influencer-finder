# Influencer-Finder
유튜버 탐색과 비교를 돕는 키워드 기반 인플루언서 검색 서비스

[서비스 링크](https://influencer-finder-eight.vercel.app/)

## 🧩 주요 기능

### 채널 검색
- 키워드 기반 하이브리드 검색 (채널명 + 영상 제목 동시 검색)
- 영상 제목으로 매칭된 채널은 해당 영상 정보를 함께 표시
- 메인 화면의 카테고리 태그로 빠른 검색
- 검색 결과 더보기(페이지네이션) 및 동일 키워드 재검색 시 결과 캐싱
- 관련도순 / 구독자 많은 순 / 최신순 정렬

### 채널 상세
- 채널 설명, 구독자 수, 최근 5개 영상 평균 조회수 제공
- 채널 최신 영상 목록 확인
- 채널 저장 기능

### 마이페이지 (컨택 관리)
- 저장한 인플루언서 리스트 조회
- 컨택 상태(미컨택 / 컨택 / 지원)별 탭 필터
- 구독자순 / 조회수순 정렬, 이름 검색
- 인플루언서 직접 추가 (컨택 포인트, 과거 컨택 시기, 소개 등 입력)

### 회원
- 회원가입 / 로그인 / 로그아웃
- 헤더 사용자 메뉴에서 마이페이지 이동 및 로그아웃

## 🛠️ 기술 스택
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Supabase (Auth, PostgreSQL)
- Zustand
- YouTube Data API
- react-hot-toast, lucide-react
- Vercel (배포)
